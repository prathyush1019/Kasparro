Parser Strategy
🧠 Phase 1 — LLM Extraction

Sends each resume's Markdown to the LLM to extract structured data (name, skills, projects, work experience). Verify the JSON output below before proceeding.

⚙️ Phase 2 — Python Scoring

Runs the deterministic Python script. Checks eligibility (Python + AI evidence), assigns base scores, and async fetches GitHub data. No LLM used here.

🤖 Phase 3 — LLM Review & Penalties

Sends base scores + resume data to the LLM. The LLM applies penalties for thin wrappers, tutorial projects, and keyword-only skills. Can only reduce scores, never increase.
